# The Visual Display of Quantitative Information

Notes from the [1983 book by Edward Tufte](https://www.edwardtufte.com/book/the-visual-display-of-quantitative-information/)
* John Tukey - Princeton statistician started the field *statistical graphics* in the 1960s

## Introduction
* Statistical graphics were invented 1750s-1800
* William Playfair (1759-1823) developed and improved fundamental graphical design
    * Wanted to replace a table of numbers with visuals representing quantitative data, *data graphics*
